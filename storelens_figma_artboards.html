StoreLens — onboarding artboards (Figma-ready)

Every screen is rendered at once as its own fixed-width frame, so an HTML→Figma import captures all of them (not just one). Recommended: the html.to.design Figma plugin → "Import from HTML" (upload this file). Each frame below imports as a separate Figma frame; select them and use right-click → Move to page if you want one screen per page. Frame width is a uniform 640 px.
